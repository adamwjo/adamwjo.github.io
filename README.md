# adamjohnson — personal site

Single static page. React 19 · Vite 8 · Tailwind v4 · Motion · Switzer · Iconoteka icons. Black on white, designed mobile-first. Deployed to GitHub Pages on push to `main`.

Start with [CONTEXT.md](CONTEXT.md) for the vocabulary and invariants, and [docs/adr](docs/adr) for why things are the way they are.

```
pnpm install
pnpm dev
```
